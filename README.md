# 🎓 Student Performance Predictor

An AI-powered machine learning web application that predicts student academic performance based on study hours, attendance, previous score, and sleep hours.

## ✨ Features

- 📚 Study hours analysis
- 📅 Attendance analysis
- 📝 Previous score analysis
- 😴 Sleep hours analysis
- 🔮 Performance prediction
- 💡 Personalized improvement suggestions
- 🎯 Personalized action plan
- 📊 Performance dashboard
- 👤 Student summary
- ✨ Smooth UI transition effects

## 🛠️ Technologies Used

- Python
- Pandas
- Scikit-learn
- Joblib
- Streamlit

## 📊 Input Parameters

The application uses four student-related factors:

- Study Hours per Day
- Attendance Percentage
- Previous Score
- Sleep Hours

## 🔮 Prediction

The machine learning model predicts the student's performance as:

- 🟢 High
- 🟡 Medium
- 🔴 Low

Based on the prediction and input values, the application provides personalized suggestions and an action plan.
